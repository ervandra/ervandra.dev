## 5. Design Direction

### 5.1 Style
- **Reference:** linear.app, vercel.com — clean, premium, modern
- **Mode:** Dark mode primary (with optional light mode toggle)
- **Typography:** Bold headings (Inter/Cal Sans or similar), clean body text
- **Accent Color:** Keep lime green (#a5ff90) or refine to a more premium green
- **Layout:** Generous whitespace, clear hierarchy, full-width sections
- **Cards:** Subtle borders, no heavy shadows, slight glass effect
- **Animations:** Smooth scroll reveals, subtle hover states, micro-interactions
- **Grid:** Consistent 12-column grid

### 5.2 Key Design Principles
- Headlines are BOLD and large — make a statement
- High contrast for readability
- Premium feel without being flashy
- Mobile-first responsive
- Performance-first (no heavy images/animations)
- Accessibility (WCAG AA minimum)

### 5.3 Visual Elements
- Custom icons or Lucide icons (replace FontAwesome)
- Project screenshots with browser mockup frames
- Subtle gradient backgrounds
- Animated code snippets or terminal in hero (optional)
- Professional headshot

## 6. Technical Architecture

### 6.1 Stack Upgrade

| Component | Current | Target |
|-----------|---------|--------|
| Framework | Next.js 12 (Pages Router) | Next.js 15 (App Router) |
| React | 18.1 | 19 (latest) |
| Node | 16.13 | 20+ (LTS) |
| TypeScript | 4.6 | 5.x |
| Styling | Tailwind 3 + Bootstrap + SCSS | Tailwind CSS 4 only |
| Animation | react-reveal (dead) | Framer Motion 11 |
| Icons | FontAwesome | Lucide React |
| Content | Hardcoded JS | MDX (for blog) + config files |
| Analytics | react-gtm-module | Next.js Script + GTM |
| Scheduling | react-calendly | Calendly embed (native) |
| Fonts | Fira Sans (SCSS) | Inter / Geist (next/font) |
| Package Manager | Yarn 1 | pnpm or bun |
| Linting | Prettier only | ESLint + Prettier |
| SEO | Minimal | next-seo / Metadata API |
| Email | Kirim.Email API | Keep or migrate to Resend |
